# 11월 18일 웹 최종 통합 검증

최신 develop, 팀원 PR #60의 지정폐기물 경고를 함께 적용했다. 처리경로 화면의 병합 충돌에서는 아래 순서를 보존했다.

1. 실제 문진 엔진으로 분류번호 확정
2. 현재 형태·물량·상태 등록
3. 사진 선택 첨부 → 후보 전체 AI 검토
4. 검토 결과에서 업체 선택 → 상대 기업 수락
5. 발송 기업 운송 시작 → 수신 기업 QR 입고
6. 실제 산출물 기록 → 중간 산출물이면 다음 업체 검토, 최종 산출물이면 완료

공정 선택 후 사진을 넣고 같은 공정을 다시 추천받는 이전 중복 흐름은 제거했다. 사진이 없으면 상태 설명만 검토하고, 비폐기물 사진은 교체 전 인수 요청을 차단한다. 문진 분류번호는 사진 때문에 임의로 바꾸지 않는다.

## 지도와 인계 표시

- 가입·기업정보·후보·인계·순환자원지도에 공통 카카오 지도 연결
- 주소 검색 결과 선택, 지도 핀 클릭/드래그 후 기존 위치 필드로 저장
- 서버에서 받은 자동차 도로 경로만 표시, 실패 시 직선 대체 없음
- 수락·운송·QR 입고를 구분하고, 기록된 이력 전체에 보라색 체크 표시
- 5초 조회 및 창 복귀 시 다른 기업의 변경 반영, 작업 중인 입력과 최신 응답 보호
- 최종 펠렛 이후 불필요한 사진/업체 재검토 제거
- 실제 완료 시 마지막 완료 단계도 체크로 표시하고 상단 처리 추적 탭 유지
- 검토 결과가 나온 뒤에는 등록/검토 시작 안내를 숨김
