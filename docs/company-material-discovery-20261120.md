# 회사 취급 소재 기준 후보 표시

2026-11-20 사용자 지시. '공정 관련 업체' 대신 **'취급 소재가 맞는 업체'**로 표시한다. 회사 자료의 소재/제품 목록으로 문의 후보를 찾고 세부 공정·반입조건은 업체와 대화로 확인한다. 사업장별 설비를 입증한 의미로 표시하지 않는다. 공정·예상 산출물은 다음 가공 후보이며 실제 확정은 B 수락과 결과 기록으로 이어진다.

server의 거리 순위에서 사업장 역할 추정 후보를 불리하게 두던 기준을 제거하고, route가 회사 차원의 소재 자료를 허용한다. 형식·증빙을 추가 질문하지 않고 다른 소재·명시 취급 제외·모델 오류·사진 모순 등 기존 제약은 유지한다.

실제 Azure 검토 후 BGF 화성 PE 후보가 1곳 표시됐고 카카오 도로14.1km, 회사의 r-PE 제품 자료 인용, 수신 계정의 인수 요청 버튼을 브라우저에서 확인했다. 별도 합성 로트가 B 처리 후 상태부터 시작한 후보 기준 시험이며 새 문진/QR 전체 E2E가 아니다. 실제 업체 연락·운영 배포는 하지 않았다.

웹108검사·Vite/Docker 빌드 통과. 적용은 route 회사 소재 기준 → server #62 거리 순위 → web #68 문구 순서다. API 필드/타입·DB·문진 엔진·완료 상태·QR 절차는 바꾸지 않았다. 에이전트 지침 영향 없음.
